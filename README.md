# LeetCode x86-64

A small collection of LeetCode problems and basic programming exercises written in x86-64 assembly. This project is for learning assembly by building familiar problems from scratch :)

The code uses GNU assembler with Intel syntax and targets Linux.

## Contents

- `basic-loop`: a simple counting loop
- `sum-array`: sums the values in an array
- `contains-duplicates`: checks an array for duplicate values
- `twosum`: solves Two Sum with a hash table
- `lib`: shared assembly code
... and more to come
